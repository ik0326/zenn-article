## v4 のサポートは 2026-12-31 で切れる

Go の Web フレームワーク [Echo](https://github.com/labstack/echo) の v5 が出たのは **2026-01-18**。最新は **v5.3.1**(2026-07-21)で、**v4 のサポート期限は 2026-12-31** です。この記事を書いている 2026-09 末時点で猶予は約 3 か月。

この記事は **上から順にコピペすれば v5 に上がる手順書**です。

まず[一括移行スクリプト](#%E3%81%BE%E3%81%9A%3A-%E4%B8%80%E6%8B%AC%E7%A7%BB%E8%A1%8C%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%97%E3%83%88)を置きます。これで**機械的に置換できる部分は終わり**です。そのあと、

- **Part 1** … スクリプトが流しているコマンドの内訳(1 つずつ確認しながら進めたい場合)
- **Part 2** … 機械的に対応できない部分。**コピペ用のコードで置き換える**
- **Part 3** … 最終確認

API 差分の詳細は公式の [API_CHANGES_V5.md](https://github.com/labstack/echo/blob/master/API_CHANGES_V5.md) が網羅しているので、ここでは叩くコマンドと貼るコードだけを並べます。掲載したコマンドとコードは、v4 のサンプルアプリを実際に v5 へ上げて動作を確認したものです。

| | |
|---|---|
| OS | macOS(Darwin 25.6.0 / arm64) |
| Go | 1.26.4 |
| 移行前 | `github.com/labstack/echo/v4` v4.15.4 |
| 移行後 | `github.com/labstack/echo/v5` v5.3.1 |

`sed -i` の書き方が GNU sed と BSD sed で違うので、コマンドは macOS 版と Linux 版を併記します。

## Echo v5 の概要

新機能ではなく、v4 で溜まった API の歪みを直すためのメジャーバージョンです。変更の柱は 4 つ。

| | 変更 | 移行作業への影響 |
|---|---|---|
| `Context` | interface → struct | ハンドラの引数が全部 `*echo.Context` に。**作業量の 9 割がここ**。Part 1 の sed で終わる |
| `Router` | 構造体 → interface(既定実装は `DefaultRouter`) | `e.Routes()` などのアクセス経路が変わる |
| Logger | 独自 interface → `log/slog` | `e.Logger` が `*slog.Logger` に。`Infof` / `Fatal` は消える |
| 起動 / シグネチャ | `e.Start*` を `StartConfig` に集約、Context を第 1 引数に統一 | **起動処理とエラーハンドラは書き直しになる**。Part 2 にコピペ用のコードを用意 |

- 要求 Go バージョンは **1.25.0 以上**(v4.15.4 も既に 1.25.0 要求なので、最新 v4 なら障壁にならない)
- インポートパスにメジャーバージョンが入るので v4 と v5 は共存できますが、**混在すると `echo.Context` と `*echo.Context` が噛み合わない**ため一気に上げます

## まず: 一括移行スクリプト

このスクリプトを流すと、**機械的に置換できる部分(Part 1)が全部終わります**。最後に残りのコンパイルエラーが出力されるので、それを Part 2 で潰していきます。個々のコマンドの意味は Part 1 で説明します。

置換結果を `git diff` で確認できるようにするため、**未コミットの変更があると Step 0 で止まります**(`ALLOW_DIRTY=1` で強行可)。`vendor/` は書き換えません。

:::details migrate-echo-v5.sh

```bash
#!/usr/bin/env bash
# Echo v4 -> v5 移行スクリプト
#   - GNU sed / BSD sed(macOS) を自動判別する
#   - vendor/ .git node_modules は書き換えない
#   - 未コミットの変更があると中断する(置換結果を git diff で確認できるようにするため)
#
# 使い方: go.mod があるディレクトリで実行する
#   bash migrate-echo-v5.sh
#   ALLOW_DIRTY=1 bash migrate-echo-v5.sh   # 上のチェックを飛ばして強行する
set -euo pipefail

die() { echo "ERROR: $*" >&2; exit 1; }

echo "==> Step 0: 前提チェック"
[ -f go.mod ] || die "go.mod がありません。モジュールのルートで実行してください。"

if git rev-parse --is-inside-work-tree >/dev/null 2>&1; then
  if [ -z "${ALLOW_DIRTY:-}" ] && [ -n "$(git status --porcelain)" ]; then
    die "未コミットの変更があります。この後 sed でファイルを書き換えるので、先に commit か stash してください(強行するなら ALLOW_DIRTY=1)。"
  fi
elif [ -z "${ALLOW_DIRTY:-}" ]; then
  die "git リポジトリではありません。置換結果を確認できないので中断します(強行するなら ALLOW_DIRTY=1)。"
fi

# BSD sed は -i にバックアップ拡張子の指定が必須
SED_INPLACE=(-i '')
if sed --version >/dev/null 2>&1; then
  SED_INPLACE=(-i)
fi

# 対象から外すディレクトリ
SKIP_DIRS=(-name vendor -o -name .git -o -name node_modules)
GREP_SKIP=(--include='*.go' --exclude-dir=vendor --exclude-dir=.git --exclude-dir=node_modules)

# v5 で消える API のパターン
DEAD_API='middleware\.(Logger|LoggerWithConfig|Timeout|TimeoutWithConfig)\b|echo\.Map\b|\.Logger\.(Fatal|Print|Printf|Debugf|Infof|Warnf|Errorf)|\.Logger\(\)\.(Print|Printf|Debugf|Infof|Warnf|Errorf)|e\.Routes\(\)|SetParamNames|SetParamValues|ParamNames\(\)|ParamValues\(\)|\*echo\.HTTPError|echo\.NewHTTPError\([^)]*,[^)]*,|FormParam|PathParamsBinder|BindPathParams|\.Response\(\)\.(Committed|Status|Size|Writer|Before|After)|e\.Start(TLS|AutoTLS|H2CServer|Server)|e\.(Shutdown|Close|Reverse|URI|URL|Host)\(|HideBanner|HidePort|e\.Debug|echo\.GetPath|NotFoundHandler|MethodNotAllowedHandler'

echo "==> Step 1: 移行前の状態を確認"
if ! { go build ./... && go vet ./... && go test ./...; }; then
  die "移行前の時点で既に失敗しています。先にここを green にしてから再実行してください。"
fi
go list -m all | grep -i 'labstack/echo' || true

echo "==> Step 2: v5 で消える API の棚卸し"
TODO_FILE=$(mktemp "${TMPDIR:-/tmp}/echo-v5-todo.XXXXXX")
grep -rnE "${GREP_SKIP[@]}" "$DEAD_API" . | tee "$TODO_FILE" || true
echo "    -> $TODO_FILE に保存"

echo "==> Step 3: sed で一括置換"
find . -type d \( "${SKIP_DIRS[@]}" \) -prune -o -type f -name '*.go' \
  -exec sed "${SED_INPLACE[@]}" -E 's/([^*[:alnum:]_.])echo\.Context/\1*echo.Context/g' {} +
find . -type d \( "${SKIP_DIRS[@]}" \) -prune -o -type f -name '*.go' \
  -exec sed "${SED_INPLACE[@]}" 's|echo/v4|echo/v5|g' {} +

echo "==> Step 4: go.mod を差し替え"
go get github.com/labstack/echo/v5@latest
go mod tidy
if [ -d vendor ]; then
  echo "    vendor/ を検出したので go mod vendor を再実行します"
  go mod vendor
fi
go list -deps ./... | grep labstack/echo || true

echo "==> Step 5: 取り残しの確認"
grep -rnE "${GREP_SKIP[@]}" '(^|[^*])echo\.Context' . || echo "    (残骸なし)"
find . -type d \( "${SKIP_DIRS[@]}" \) -prune -o -type f -name '*.go' -exec gofmt -l {} +

echo "==> ここから Part 2(手作業)。残りのエラーを出す"
go build -gcflags=-e ./... || true
go vet ./... || true
```

:::

Part 1 を 1 つずつ確認しながら進めたい場合は、次章のコマンドを順に叩いてください。

# Part 1. 機械的に移行する

このパートは全部コマンドです。上の `migrate-echo-v5.sh` が流しているのはこの Step 1 〜 5 です。

## Step 1. 下準備

移行前が green だった記録を残してから始めます。

```bash
git switch -c chore/echo-v5
go build ./... && go vet ./... && go test ./...
```

依存側が v5 に対応しているかを先に確認します。

```bash
go list -m all | grep -i 'labstack/echo'
go mod graph | grep 'labstack/echo'
```

公式サテライトは v5 系が出ています(2026-09 時点)。

| モジュール | v5 対応タグ |
|---|---|
| `github.com/labstack/echo-contrib/v5` | v5.0.1 |
| `github.com/labstack/echo-jwt/v5` | v5.0.2 |

未対応のものが `echo/v4` を引いている場合は、犯人を特定します。

```bash
go mod why -m github.com/labstack/echo/v4
```

## Step 2. 作業量を見積もる

v5 で消える API を先に洗い出します。ここで出た行が Part 2 で直す対象です。

```bash
grep -rnE --include='*.go' --exclude-dir=vendor \
  'middleware\.(Logger|LoggerWithConfig|Timeout|TimeoutWithConfig)\b|echo\.Map\b|\.Logger\.(Fatal|Print|Printf|Debugf|Infof|Warnf|Errorf)|\.Logger\(\)\.(Print|Printf|Debugf|Infof|Warnf|Errorf)|e\.Routes\(\)|SetParamNames|SetParamValues|ParamNames\(\)|ParamValues\(\)|\*echo\.HTTPError|echo\.NewHTTPError\([^)]*,[^)]*,|FormParam|PathParamsBinder|BindPathParams|\.Response\(\)\.(Committed|Status|Size|Writer|Before|After)|e\.Start(TLS|AutoTLS|H2CServer|Server)|e\.(Shutdown|Close|Reverse|URI|URL|Host)\(|HideBanner|HidePort|e\.Debug|echo\.GetPath|NotFoundHandler|MethodNotAllowedHandler' \
  .
```

## Step 3. sed で一括置換

`echo.Context` → `*echo.Context` と、インポートパス `echo/v4` → `echo/v5` を置換します。

```bash
# macOS (BSD sed)
find . -type d \( -name vendor -o -name .git \) -prune -o -type f -name '*.go' \
  -exec sed -i '' -E 's/([^*[:alnum:]_.])echo\.Context/\1*echo.Context/g' {} +
find . -type d \( -name vendor -o -name .git \) -prune -o -type f -name '*.go' \
  -exec sed -i '' 's|echo/v4|echo/v5|g' {} +
```

```bash
# Linux (GNU sed)
find . -type d \( -name vendor -o -name .git \) -prune -o -type f -name '*.go' \
  -exec sed -i -E 's/([^*[:alnum:]_.])echo\.Context/\1*echo.Context/g' {} +
find . -type d \( -name vendor -o -name .git \) -prune -o -type f -name '*.go' \
  -exec sed -i 's|echo/v4|echo/v5|g' {} +
```

`vendor` を除外しているのは、そこに `echo/v4` のソースが入っていると一緒に書き換えて壊してしまうからです。

正規表現は「直前が `*` でない `echo.Context` を置換する」という意味です。`(c echo.Context)` だけでなく `func(echo.Context) error`、`[]echo.Context`、`map[string]echo.Context`、interface のメソッド宣言も拾い、何回流しても `**echo.Context` にはなりません。**文字列リテラルとコメントも巻き込む**ので、Step 5 で `git diff` を見ます。

## Step 4. go.mod を差し替える

```bash
go get github.com/labstack/echo/v5@latest
go mod tidy
go list -deps ./... | grep labstack/echo
```

`vendor/` を使っているなら、`go mod tidy` のあとに `go mod vendor` を流し直します。これを忘れると `go build` が「vendor/modules.txt と go.mod が食い違っている」と言って止まります。

`go mod edit -go=1.25.0` は要りません。v5 の `go.mod` が `go 1.25.0` を要求しているので、**`go get` が go ディレクティブを自動で上げます**。`go 1.22.0` の go.mod で試すと `go get` 一発で `go 1.25.0` に書き換わりました(手元の go コマンドが 1.25 未満の場合は、必要な toolchain が自動ダウンロードされます)。

最後のコマンドの出力が v5 だけになっていれば OK です。

```
github.com/labstack/echo/v5
github.com/labstack/echo/v5/middleware
```

`echo/v4` が混ざっていたら Step 1 の `go mod why -m` に戻ります。

## Step 5. 取り残しを確認する

```bash
# 置換漏れ(ヒットは文字列リテラルとコメントだけになるはず)
grep -rnE --include='*.go' --exclude-dir=vendor '(^|[^*])echo\.Context' .

# 整形が壊れていないか
find . -type d \( -name vendor -o -name .git \) -prune -o -type f -name '*.go' -exec gofmt -l {} +

# 置換内容の目視
git diff --stat
git diff -- '*.go' | grep -E '^\+.*\*echo\.Context' | sed 's/^+//' | sort | uniq -c | sort -rn | head -30
```

# Part 2. 機械的に対応できない部分を雛形で置き換える

まず、残っているエラーを全部出します。`go build ./...` は `_test.go` をコンパイルしないので、テストの移行漏れが見えません。

```bash
go build -gcflags=-e ./...   # 打ち切りなしで全エラーを出す
go vet ./...                 # テストコードも型検査する
go test -run '^$' ./...      # テストをビルドだけして実行しない
```

`-gcflags=-e` がないと 1 パッケージ 10 エラーで `too many errors` と打ち切られます。`go test -run '^$'` はどのテスト名にもマッチしないので、コンパイルだけが走ります。

以降、**2-1 〜 2-3 はコードを丸ごと差し替える**のが速いです。2-4 は該当する場合だけ対応し、2-5 は残りをエラーメッセージから引く表です。

:::message alert
**2-3 と 2-4 はコンパイルもテストも通ってしまいます。** ビルドが通ったからといって飛ばさないでください。
:::

## 2-1. 起動処理を `StartConfig` に置き換える

v5 では `e.Start*` 系のメソッドと、`e.Server` / `e.TLSServer` / `e.Listener` / `e.AutoTLSManager` / `e.HideBanner` / `e.HidePort` / `e.ListenerNetwork` といったフィールドがまとめて廃止され、**`echo.StartConfig` に集約されました**。あわせて次の 2 つも消えています。

- `e.Shutdown(ctx)` / `e.Close()` … 廃止。**`StartConfig.Start(ctx, e)` が ctx のキャンセルで graceful shutdown します**(`GracefulTimeout` は `0` なら 10 秒、負値を入れると graceful shutdown 自体が無効)
- `e.Debug` … 廃止。`e.Logger` のレベルで代用します

以下、v4 の書き方ごとにそのまま貼れるコードを並べます。どのパターンでも、graceful shutdown のトリガーになる ctx を先に作ります。

```go
import (
	"context"
	"os"
	"os/signal"
	"syscall"
)

// SIGINT / SIGTERM で ctx をキャンセルする。これが graceful shutdown のトリガーになる
func appContext() (context.Context, context.CancelFunc) {
	return signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
}
```

### `e.Start()` / `e.StartServer()` / `e.Server.XxxTimeout` の置き換え

```go
func run(e *echo.Echo) {
	ctx, stop := appContext()
	defer stop()

	sc := echo.StartConfig{
		Address:    ":8080",
		HideBanner: true,
		HidePort:   true,

		// LB の切り離し完了 + 処理中リクエストの最長時間より長く取る
		GracefulTimeout: 30 * time.Second,
		OnShutdownError: func(err error) {
			e.Logger.Error("graceful shutdown timed out", slog.Any("err", err))
		},

		BeforeServeFunc: func(s *http.Server) error {
			s.ReadHeaderTimeout = 5 * time.Second // Slowloris 対策
			s.ReadTimeout = 30 * time.Second      // ヘッダ + ボディの読み取り上限
			s.WriteTimeout = 30 * time.Second     // SSE / ストリーミングがあるなら 0
			s.IdleTimeout = 120 * time.Second     // LB の idle timeout より長く
			s.MaxHeaderBytes = 1 << 20            // 1 MiB
			return nil
		},
	}

	if err := sc.Start(ctx, e); err != nil {
		e.Logger.Error("server stopped", slog.Any("err", err))
		os.Exit(1)
	}
}
```

値の決め方です。数字は出発点なので、自分のワークロードで調整してください。

| 設定 | 出発点 | 決め方 / 注意 |
|---|---|---|
| `GracefulTimeout` | 30s | LB の切り離し完了時間 + 最長リクエスト処理時間より**長く**。k8s なら `terminationGracePeriodSeconds` より**短く**(超えると SIGKILL される) |
| `ReadHeaderTimeout` | 5s | Slowloris 対策。`0` だと `ReadTimeout` にフォールバックするので、ヘッダだけ短くしたいなら明示が必要 |
| `ReadTimeout` | 30s | ヘッダ + ボディの読み取り上限。**大きいアップロードがあるなら `0`** にして、`middleware.BodyLimit` とハンドラ側で制御する |
| `WriteTimeout` | 30s | レスポンス書き込みの上限。**SSE / ストリーミング / 大きなファイル配信があるなら `0`**(v5 の既定も `0`) |
| `IdleTimeout` | 120s | keep-alive 接続の待機上限。**LB の idle timeout(ALB の既定は 60s)より長く**。逆にするとサーバが先に接続を閉じて 502 が出る |
| `MaxHeaderBytes` | 1 MiB | `http.DefaultMaxHeaderBytes` と同値。明示しておくと意図が残る |

:::message
`StartConfig.Start` は ctx がキャンセルされた時点で `http.Server.Shutdown` を呼び、**listener を即座に閉じます**。k8s では LB のエンドポイント更新が届く前に閉じると 502 が出るので、`preStop` に数秒の sleep を入れるなど Pod 側の設定と合わせてください(Echo の設定ではカバーできない部分です)。
:::

### `e.StartTLS()` の置き換え

`certFile` / `keyFile` は `string` ならパス、`[]byte` なら証明書そのものとして扱われます。

```go
func runTLS(e *echo.Echo) error {
	ctx, stop := appContext()
	defer stop()

	sc := echo.StartConfig{Address: ":443"}
	return sc.StartTLS(ctx, e, "cert.pem", "key.pem")
}
```

### `e.StartAutoTLS()` の置き換え

v5 から `e.AutoTLSManager` が消えたので、`autocert.Manager` を自分で持って `TLSConfig` に渡します。この場合呼ぶのは `StartTLS` ではなく `Start` です。

```go
import "golang.org/x/crypto/acme/autocert"

func runAutoTLS(e *echo.Echo) error {
	ctx, stop := appContext()
	defer stop()

	m := &autocert.Manager{
		Prompt:     autocert.AcceptTOS,
		HostPolicy: autocert.HostWhitelist("example.com"),
		Cache:      autocert.DirCache("/var/www/.cache"),
	}
	sc := echo.StartConfig{Address: ":443", TLSConfig: m.TLSConfig()}
	return sc.Start(ctx, e)
}
```

### `e.StartH2CServer()` の置き換え

`StartConfig.Start` は `http.Handler` を取るので、`h2c.NewHandler` でラップしたものを渡します。

```go
import (
	"golang.org/x/net/http2"
	"golang.org/x/net/http2/h2c"
)

func runH2C(e *echo.Echo) error {
	ctx, stop := appContext()
	defer stop()

	h2s := &http2.Server{MaxConcurrentStreams: 250}
	sc := echo.StartConfig{Address: ":8080"}
	return sc.Start(ctx, h2c.NewHandler(e, h2s))
}
```

### 自前の listener を渡す / テストでポート 0 を使う(`e.Listener` / `e.ListenerAddr()`)

`ListenerAddrFunc` で実際にバインドされたアドレスを受け取れます。`:0` で起動するテストはこれで書けます。

```go
func runWithListener(e *echo.Echo) error {
	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		return err
	}
	sc := echo.StartConfig{
		Listener:         ln,
		HideBanner:       true,
		ListenerAddrFunc: func(addr net.Addr) { e.Logger.Info("listening", slog.String("addr", addr.String())) },
	}
	return sc.Start(context.Background(), e)
}
```

### Unix domain socket(`e.ListenerNetwork`)

```go
func runUnix(e *echo.Echo) error {
	sc := echo.StartConfig{Address: "/tmp/echo.sock", ListenerNetwork: "unix"}
	return sc.Start(context.Background(), e)
}
```

## 2-2. Logger を `slog` に置き換える

`e.Logger` の型が `*slog.Logger` になったので、`Infof` / `Errorf` / `Fatal` は全部消えます。

```go
e := echo.New()
e.Logger = slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelInfo}))
```

| v4 | v5 |
|---|---|
| `e.Logger.Infof("route: %s", p)` | `e.Logger.Info("route", slog.String("path", p))` |
| `c.Logger().Errorf("failed: %v", err)` | `c.Logger().Error("failed", slog.Any("err", err))` |
| `e.Logger.Fatal(err)` | `slog` に Fatal はない → `e.Logger.Error(...)` + `os.Exit(1)`(2-1 参照) |
| `e.StdLogger` | 廃止。必要なら `slog.NewLogLogger(e.Logger.Handler(), slog.LevelError)` |
| `middleware.Logger()` | `middleware.RequestLogger()` |
| `middleware.LoggerWithConfig(...)` | `middleware.RequestLoggerWithConfig(...)` |

## 2-3. エラーハンドラを書き換える

```go
func errorHandler(c *echo.Context, err error) {
	// RequestLogger が既にレスポンスを書いている場合は何もしない
	if resp, _ := echo.UnwrapResponse(c.Response()); resp != nil && resp.Committed {
		return
	}
	// *HTTPError も ErrNotFound などの sentinel も Wrap 済みのものも拾える
	code := echo.StatusCode(err)
	if code == 0 {
		code = http.StatusInternalServerError
	}
	c.Logger().Error("request failed", slog.Any("err", err))
	_ = c.JSON(code, map[string]any{"error": http.StatusText(code)})
}
```

## 2-4. `RealIP()` を使っているなら `IPExtractor` を明示する

v4 は `X-Forwarded-For` → `X-Real-IP` → `RemoteAddr` の順に見ていましたが、**v5 の既定は `RemoteAddr` だけ**です。ロードバランサ配下ではクライアント IP が LB の IP になり、IP ベースのレートリミットや監査ログが壊れます。これもコンパイルエラーになりません。

```go
// 推奨: XFF を読むが、信頼できるホップだけを剥がす
e.IPExtractor = echo.ExtractIPFromXFFHeader(
	echo.TrustLoopback(true),
	echo.TrustPrivateNet(true),
)

// X-Real-IP を使う環境なら
e.IPExtractor = echo.ExtractIPFromRealIPHeader(echo.TrustPrivateNet(true))

// v4 と同じ挙動に戻す(ヘッダを検証しないので偽装可能。一時しのぎ)
e.IPExtractor = echo.LegacyIPExtractor()
```

## 2-5. 残りはこの表から引く

エラーメッセージで検索してください。

### Context

| v4 | v5 |
|---|---|
| `c.Response()`(`*echo.Response`) | `http.ResponseWriter` を返す |
| `c.Response().Committed` / `.Status` / `.Size` | `resp, _ := echo.UnwrapResponse(c.Response())` → `resp.Committed` |
| `c.ParamNames()` / `c.ParamValues()` | `c.PathValues()` |
| `c.SetParamNames(...)` / `c.SetParamValues(...)` | `c.SetPathValues(echo.PathValues{{Name: "id", Value: "7"}})` |
| `echo.Map` | 廃止 → `map[string]any` |
| `echo.GetPath(r)` | `r.URL.Path` / `r.URL.RawPath` |

### ルーティング

| v4 | v5 |
|---|---|
| `e.Routes()` | `e.Router().Routes()` |
| `e.Reverse(name, ...)` | `e.Router().Routes().Reverse(name, ...)` |
| `e.GET(...)` → `*echo.Route` | `echo.RouteInfo`(値型) |
| `e.Any(...)` → `[]*echo.Route` | `echo.RouteInfo` |
| `g.Static(...)` → 戻り値なし | `echo.RouteInfo`(ミドルウェアも受け取る) |
| `e.URI` / `e.URL` / `e.Host` / `e.Routers` | 廃止 |

### Bind / 値取り出し

| v4 | v5 |
|---|---|
| `echo.FormParam[T](c, ...)` | `echo.FormValue[T](c, ...)` |
| `echo.PathParamsBinder(c)` | `echo.PathValuesBinder(c)` |
| `b.BindPathParams(c, i)` | `echo.BindPathValues(c, target)` |
| `Binder.Bind(i, c)` | `Binder.Bind(c, target)` ← **引数が逆** |
| `Renderer.Render(w, name, data, c)` | `Renderer.Render(c, w, name, data)` ← **Context が先頭** |

### ミドルウェア

| v4 | v5 |
|---|---|
| `middleware.Timeout()` / `TimeoutWithConfig` | 廃止。`middleware.ContextTimeout()` はリクエストの ctx を cancel するだけで挙動が違うので、ハンドラを打ち切りたいなら `http.TimeoutHandler` で `e` をラップする |
| `middleware.CORSWithConfig(CORSConfig{AllowOrigins: []string{"*"}})` | `middleware.CORS("*")` |
| `middleware.BodyLimit("2M")` | `middleware.BodyLimit(2 * 1024 * middleware.KB)`(バイト数の `int64`) |
| `middleware.DefaultCORSConfig` ほか `Default*Config` 群 | 廃止 |
| `middleware.TrailingSlashConfig` | `AddTrailingSlashConfig` / `RemoveTrailingSlashConfig` に分割 |
| `Skipper func(c echo.Context) bool` | `Skipper func(c *echo.Context) bool` |
| `BasicAuthValidator func(user, pass string, c echo.Context)` | `func(c *echo.Context, user, password string) (bool, error)` |
| `KeyAuthValidator func(key string, c echo.Context)` | `func(c *echo.Context, key string, source ExtractorSource) (bool, error)` |

## 付録: 移行後の `main.go` 全文

Part 2 の 2-1 〜 2-4 を適用した状態です。

:::details main.go

```go
package main

import (
	"context"
	"log/slog"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"

	"github.com/labstack/echo/v5"
	"github.com/labstack/echo/v5/middleware"
)

func main() {
	e := echo.New()
	e.Logger = slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelInfo}))
	e.IPExtractor = echo.ExtractIPFromXFFHeader(echo.TrustLoopback(true), echo.TrustPrivateNet(true))
	e.HTTPErrorHandler = errorHandler

	e.Use(middleware.RequestLogger())
	e.Use(middleware.Recover())
	e.Use(middleware.CORS("*"))

	e.GET("/health", func(c *echo.Context) error {
		return c.JSON(http.StatusOK, map[string]any{"status": "ok"})
	})

	for _, r := range e.Router().Routes() {
		e.Logger.Info("route", slog.String("method", r.Method), slog.String("path", r.Path))
	}

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()

	sc := echo.StartConfig{
		Address:         ":8080",
		HideBanner:      true,
		HidePort:        true,
		GracefulTimeout: 30 * time.Second,
		OnShutdownError: func(err error) {
			e.Logger.Error("graceful shutdown timed out", slog.Any("err", err))
		},
		BeforeServeFunc: func(s *http.Server) error {
			s.ReadHeaderTimeout = 5 * time.Second
			s.ReadTimeout = 30 * time.Second
			s.WriteTimeout = 30 * time.Second
			s.IdleTimeout = 120 * time.Second
			s.MaxHeaderBytes = 1 << 20
			return nil
		},
	}
	if err := sc.Start(ctx, e); err != nil {
		e.Logger.Error("server stopped", slog.Any("err", err))
		os.Exit(1)
	}
}

func errorHandler(c *echo.Context, err error) {
	if resp, _ := echo.UnwrapResponse(c.Response()); resp != nil && resp.Committed {
		return
	}
	code := echo.StatusCode(err)
	if code == 0 {
		code = http.StatusInternalServerError
	}
	c.Logger().Error("request failed", slog.Any("err", err))
	_ = c.JSON(code, map[string]any{"error": http.StatusText(code)})
}
```
